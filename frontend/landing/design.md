# Diseño de Logo — SAAVIA

Crear un logo profesional y moderno para una empresa de tecnología llamada **SAAVIA**.

## Identidad de marca

**Nombre:** SAAVIA

**Concepto:** Plataforma de tecnología y gestión empresarial que ayuda a las empresas a centralizar sus operaciones, automatizar procesos y crecer.

SAAVIA nace como una plataforma ERP/SaaS, pero la identidad visual debe ser suficientemente amplia para que la empresa pueda evolucionar hacia otros productos tecnológicos.

### Conceptos que debe transmitir

* Tecnología
* Innovación
* Conectividad
* Crecimiento
* Confianza
* Inteligencia
* Simplicidad
* Organización
* Escalabilidad
* Modernidad

## Dirección visual

Crear un logo **minimalista, elegante y tecnológico**, inspirado en marcas modernas de SaaS y empresas de tecnología.

Evitar que parezca un software contable tradicional.

El símbolo debe ser reconocible incluso sin el texto "SAAVIA".

### Símbolo

Crear un isotipo abstracto basado sutilmente en la letra **S** de SAAVIA.

La "S" puede construirse mediante:

* líneas conectadas;
* formas geométricas;
* nodos;
* caminos o flujos;
* elementos que sugieran conexión y crecimiento.

La construcción debe ser simple y memorable.

El isotipo debe funcionar tanto como:

* logo principal;
* favicon;
* icono de aplicación;
* avatar de redes sociales;
* icono del dashboard;
* elemento de una aplicación móvil.

No utilizar símbolos literales de:

* engranajes;
* calculadoras;
* facturas;
* gráficos financieros;
* edificios;
* maletines;
* monedas;
* documentos.

## Tipografía

Utilizar una tipografía:

* Sans-serif
* Moderna
* Geométrica
* Limpia
* Profesional
* Excelente legibilidad

El texto debe decir exactamente:

**SAAVIA**

Preferentemente en mayúsculas.

El espaciado entre letras debe ser ligeramente amplio para transmitir sofisticación.

## Colores

Utilizar principalmente una combinación de **azul y verde**.

### Azul

Representa:

* confianza;
* tecnología;
* estabilidad;
* seguridad.

### Verde

Representa:

* crecimiento;
* evolución;
* resultados;
* innovación.

Se puede utilizar un degradado sutil de azul hacia verde, pero debe ser elegante y discreto.

El logo también debe funcionar perfectamente en:

* negro;
* blanco;
* monocromático;
* fondo claro;
* fondo oscuro.

## Estilo

Referencia estética:

**Modern SaaS + Fintech + Enterprise Technology**

Debe sentirse como una empresa tecnológica seria que podría competir internacionalmente.

Evitar estilos:

* infantiles;
* caricaturescos;
* demasiado corporativos de los años 2000;
* excesivamente complejos;
* genéricos;
* logos con demasiados detalles.

## Composición

Crear principalmente una versión horizontal:

[ ISOTIPO ] SAAVIA

Y preparar variantes:

1. Logo horizontal con isotipo + SAAVIA.
2. Logo únicamente con isotipo.
3. Logo monocromático.
4. Versión para fondo oscuro.
5. Versión para fondo claro.

## Sensación final

Al observar el logo, debería transmitir:

> "Esta es una empresa tecnológica moderna, confiable y preparada para hacer crecer negocios."

No debe parecer simplemente un ERP.

Debe parecer una **marca de tecnología con potencial para convertirse en una plataforma SaaS internacional**.

## Entrega

Generar el logo con:

* fondo transparente;
* alta resolución;
* bordes limpios;
* geometría precisa;
* excelente legibilidad;
* espacio adecuado alrededor del logo.

El resultado debe ser profesional y apto para utilizarse en una landing page, aplicación web, documentos comerciales, redes sociales y presentación corporativa.
