# Prompt — Landing Page SAAVIA NEXO

## Objetivo

Crear una landing page moderna, profesional y comercial para **SAAVIA NEXO**, una plataforma de gestión empresarial desarrollada por **SAAVIA**.

La landing debe presentar NEXO como un producto SaaS moderno orientado principalmente a pequeñas y medianas empresas, transmitiendo confianza, tecnología, simplicidad y capacidad de crecimiento.

La página debe sentirse como la presentación de una **startup tecnológica real**, no como la documentación de un ERP.

---

# 1. Arquitectura de marca

Es fundamental respetar esta estructura:

### Empresa

**SAAVIA**

Empresa de tecnología responsable del desarrollo de soluciones digitales para empresas.

### Producto

**NEXO**

Plataforma de gestión empresarial de SAAVIA.

La relación visual debe ser:

> **SAAVIA**  
> Tecnología que hace avanzar tu empresa.

y:

> **NEXO**  
> Plataforma de gestión empresarial.

En algunos lugares puede utilizarse:

> **NEXO by SAAVIA**

No utilizar "SAAVIA ERP" como nombre principal del producto.

---

# 2. Objetivo comercial de la landing

La landing debe conseguir que un visitante entienda en pocos segundos:

1. Qué es NEXO.
2. Qué problema resuelve.
3. Para quién está pensado.
4. Qué áreas de una empresa puede centralizar.
5. Por qué es diferente.
6. Cómo puede comenzar a utilizarlo.

El visitante debe terminar pensando:

> "Con NEXO puedo centralizar la gestión de mi empresa en una sola plataforma."

El elemento visual principal debe ser una representación moderna del dashboard de NEXO.

No crear un dashboard extremadamente complejo.

Mostrar una interfaz elegante con tarjetas representando:

- Ventas
- Clientes
- Inventario
- Tesorería
- DTE
- Actividad reciente

Utilizar gráficos simples y elementos visuales relacionados con gestión empresarial.

# 5. Sección: El problema

Título:

## Tu empresa crece. Tu forma de gestionarla también debe hacerlo.

Texto:

A medida que un negocio crece, también aumentan los procesos, clientes, productos, ventas, pagos y documentos.

Cuando cada área utiliza herramientas diferentes, la información termina dispersa.

NEXO nace para centralizar esa operación.

Mostrar visualmente:

```text
Antes

Ventas       → Sistema
Inventario   → Excel
Clientes     → Otro sistema
Pagos        → Planilla
DTE          → Otro proceso


Después

              ┌───────────┐
              │   NEXO    │
              └─────┬─────┘
                    │
       ┌────────────┼────────────┐
       ▼            ▼            ▼
    Ventas      Inventario    Clientes
       │            │            │
       └────────────┼────────────┘
                    │
              Tesorería + DTE
```

# 6. Sección: Una plataforma para toda tu operación

Título:

## Todo conectado. Todo en un solo lugar.

Explicar que NEXO permite centralizar las principales operaciones de una empresa.

Crear tarjetas para:

### Ventas

Gestiona las operaciones comerciales y mantén el control de tus ventas.

### Clientes

Centraliza la información de tus clientes y su historial comercial.

### Productos

Administra tu catálogo y la información asociada a tus productos.

### Inventario

Controla existencias y movimientos de productos.

### Bodegas

Organiza y administra el inventario según tus diferentes ubicaciones.

### Tesorería

Controla cuentas por cobrar, pagos y movimientos asociados a tus operaciones.

### DTE

Gestiona documentos tributarios electrónicos como parte del flujo de tu negocio.

### Reportes

Obtén información de tu operación para facilitar la toma de decisiones.

No inventar funcionalidades que no estén implementadas actualmente.

La identidad debe seguir el concepto desarrollado para SAAVIA.

Utilizar una tipografía sans-serif moderna.

Debe transmitir:

- Tecnología
- Claridad
- Profesionalismo
- Modernidad

Jerarquía clara entre:

- H1
- H2
- H3
- párrafos
- botones

# 17. Estilo general

La landing debe inspirarse visualmente en:

**Modern SaaS + Fintech + Enterprise Technology**

Características:

- mucho espacio en blanco;
- cards modernas;
- bordes suaves;
- sombras muy sutiles;
- iconografía minimalista;
- microinteracciones;
- animaciones discretas;
- excelente responsive;
- diseño premium.

No utilizar:

- neumorphism;
- exceso de glassmorphism;
- gradientes exagerados;
- animaciones excesivas;
- ilustraciones infantiles;
- stock photos genéricas;
- fotografías de oficinas genéricas.

---

# 22. Requisito importante

La landing NO debe parecer una pantalla del sistema.

Debe parecer la página oficial de una **empresa tecnológica que tiene un producto SaaS propio**.

La jerarquía conceptual debe ser:

```text
SAAVIA
Empresa tecnológica
       │
       ▼
NEXO
Producto principal
       │
       ▼
Gestión empresarial
       │
       ├── Ventas
       ├── Clientes
       ├── Productos
       ├── Inventario
       ├── Bodegas
       ├── Tesorería
       └── DTE
```

El resultado final debe transmitir:

> **SAAVIA construye tecnología.  
> NEXO conecta y gestiona tu empresa.**

La landing debe sentirse como el inicio de una marca SaaS seria, escalable y preparada para crecer internacionalmente.
